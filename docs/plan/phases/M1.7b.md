# M1.7b: Bootstrap from the first test PR

**Goal:** a repository whose default branch has no protected files adopts SuiteWard from the first PR that carries tests ([ADR 0010](../../decisions/0010-repository-bootstrap.md), "New repository or repository without an initial test contract"): a bootstrap proposal on that PR, a readiness check after the owner's approval, and V1 promoted from the exact integrated revision after the merge.

**Depends on:** M1.7 (merge detection and the integrated source). Moved into the MVP by the owner on 2026-10-14 (ADR 0010 amendment).

Refined when M1.7 is merged.
