# SuiteWard brand

The mark is a shield holding a test list with one approved check: the test contract, guarded. The SVG files are the sources; the PNG files are exports of them.

| File | Use |
| --- | --- |
| `suiteward-mark.svg` | The mark, at 48 px and above. |
| `suiteward-mark-small.svg` | The mark below 48 px, such as favicons and avatars. Its outline and bars are thicker so they survive downscaling. |
| `suiteward-github-app.png` | The GitHub App logo: 512 × 512, transparent, the small-size mark with a margin. |
| `suiteward-logo.svg`, `suiteward-logo.png` | The horizontal logo for light backgrounds. |
| `suiteward-logo-dark.svg`, `suiteward-logo-dark.png` | The horizontal logo for dark backgrounds. |

## Colors

| Name | Hex | Role |
| --- | --- | --- |
| Ink | `#12202F` | The shield, and the wordmark on light backgrounds. |
| Green | `#3DD6A0` | The outline and the check: approval. |
| Paper | `#F4F1EA` | The test bars, and the wordmark on dark backgrounds. |

The green outline separates the shield from dark backgrounds, so keep it in every use. Do not recolor, rotate or stretch the mark.

## Wordmark

The wordmark is "Suite" in Inter Regular and "Ward" in Inter SemiBold, converted to outlines, so the files need no font. Inter is licensed under the SIL Open Font License 1.1.
