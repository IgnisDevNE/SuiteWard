# M1.6b: Assessment and check

**Goal:** assess the exact head of each open PR against the canonical contract and publish `SuiteWard / Contract` (D-CHECKS, ADR 0015) through the outbox.

**Depends on:** M1.6a.

Refined when M1.6a is merged. Known inputs:
- PR-head integrity assessments;
- new proposal revisions for protected changes;
- check publication with POST only, because the latest run with the name wins (S1);
- the payload carries a generation instead of a state, so a delayed `success` cannot land after a revoke;
- the check summary includes the installation tier (D-TIER);
- the owner-invalid `failure`.
