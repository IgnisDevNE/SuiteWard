# M1.7: Promotion on merge

**Goal:** after a confirmed merge, promote exactly the approved, integrated contract, and report clearly when promotion is impossible.

**Decisions:** D-INTEGRATION (settle from S1 findings); ADR 0014.

**Exit:** for each supported merge method the integrated source is resolved exactly and the canonical version advances atomically with its artifacts; unsupported methods, same-SHA ambiguity and unapproved integrated changes produce an explicit failing state with guidance; corrections use a corrective PR.

## Tasks (refined before start)

- **M1.7-A Integrated source resolution** — per supported merge method; explicit unsupported state.
- **M1.7-B Promotion job** — River job calling `Promote`/`Correct` inside the unit of work; artifact bytes written to the content store before `RecordPromotion`; outcome publication.
- **M1.7-C Periodic integrity verification** — re-verify stored canonical bytes on a schedule (replaces per-load verification removed in R1).
