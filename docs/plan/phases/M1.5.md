# M1.5: Owner and trust

**Goal:** connect a verified human owner, enroll the TOTP secret the agent cannot reach, classify the installation tier honestly, and verify that GitHub actually enforces the required checks.

**Decisions:** D-TRUST (ADR 0027), D-IDENTITY, D-PROTECTION (settle before this phase starts, using S1 findings); ADR 0016 amendment (verification only in the MVP).

**Exit:** a setup flow binds the owner's GitHub identity, enrolls TOTP, records the tier (isolated or co-located) and shows it in status; protection verification reports enforced, missing `SuiteWard / Contract`, missing project test check, or enforcement unavailable (for example a private repository on GitHub Free), each with manual instructions.

## Tasks (refined before start)

- **M1.5-A Owner setup and TOTP enrollment** — local setup command, owner identity verification, TOTP secret storage inside the instance, replay-protected verification (global single use per step, evaluated against the comment's `created_at`).
- **M1.5-B Installation tier** — detect and record isolated versus co-located deployment from configuration and environment; surface it in status and in the check summary.
- **M1.5-C Protection verification** — read effective branch protection and rulesets; compute the required-check status; distinct states and manual instructions.
