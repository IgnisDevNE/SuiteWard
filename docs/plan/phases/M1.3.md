# M1.3: Scope, inventory and existing-baseline bootstrap

**Goal:** turn a repository's `.suiteward.yml` and file tree into an exact protected inventory, with protected defaults that a candidate cannot weaken, and establish the first canonical contract from a pinned main-branch commit.

**Decisions:** D-SCOPE, D-SCOPE-DEFAULTS, D-APPROVAL-CONTEXT (accepted); ADR 0013 amendment (protected defaults include `.github/workflows/**`, test runner configuration, and test scripts).

**Exit:** given a repository tree, SuiteWard produces a deterministic inventory and proposal revision; scope reductions are classified as protection reductions; bootstrap creates the first canonical through the existing-baseline path.

## Tasks

The orchestrator split the original A and C tasks when the phase started (2026-10-11): the pattern matcher has no dependency and is the first real [Orbit](../orbit.md) task, and the proposal revision write consumes only existing contract types, so it runs in the first wave.

| Wave | Task | Owns | Executor |
| --- | --- | --- | --- |
| 1 | **A1 Scope patterns** | `internal/domain/scope/pattern*.go`; the exported path rule in `internal/domain/artifact/manifest.go` | Orbit (`medium`) |
| 1 | **C0 Contract update** | "Proposal revisions" in [persistence](../../contracts/persistence.md), D-SCOPE-DEFAULTS, this page | orchestrator |
| 1 | **C1 Proposal revision write** | `Tx.AppendProposalRevision`, `ReviseProposal`, the in-memory fake, the conformance suite and the PostgreSQL adapter | `sw-implementer` |
| 2 | **A2 Declaration** | `internal/domain/scope/declaration*.go`; `go.mod`, `go.sum` | Orbit (`high`) |
| 3 | **B Inventory** | `internal/application/inventory/**` | Orbit (`high`) |
| 4 | **C2 Bootstrap from an inventory** | use-case additions in `internal/application/governance/**` | `sw-implementer` |

- **A1** — gitignore-style patterns (D-SCOPE): anchoring, directory-only patterns, `**`, case sensitivity, rejection of negation, backslashes and dot segments. Table tests.
- **A2** — parse the declaration (YAML; `include`, `exclude`, `runner`), merge with the fixed defaults of D-SCOPE-DEFAULTS, compute the declaration digest over raw bytes plus normalized rules, reject invalid declarations while the governing scope stays in force. Table tests including invalid declarations and reduction attempts.
- **B** — from a source tree abstraction (interface; filesystem fake in tests), compute the protected inventory, its manifest and scope digest, and the covered inputs; reject symlinks and submodules inside scope; classify changes against the canonical contract (unchanged, implementation-only, protected change, scope reduction).
- **C1** — the first proposal write path outside `Seed`, per the contract: create or revise a proposal inside the unit of work, no revision for unchanged coverage, conformance and PostgreSQL tests, and the test where a proposal blocked by `CanonicalChanged` is revised against the new canonical and promotes only after fresh exact approval (R1 used a stand-in proposal because no revision write path existed).
- **C2** — create a proposal revision from an inventory and run the existing-baseline bootstrap from it.
